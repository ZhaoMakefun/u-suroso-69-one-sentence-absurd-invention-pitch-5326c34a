# One-Sentence Absurd Invention Pitch

One sentence pitching the Remote Finder 3000, a TV remote that fixes the tiny everyday annoyance of losing it down the sofa: the moment it goes missing it screams its own location in a tiny panicked voice — and files a restraining order against the sofa cushions. The laugh comes from the invention itself, a remote that treats being lost as a legal emergency.

## Run it

```sh
python3 main.py
```

Writes one sentence of UTF-8 text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Python 3, standard library only, no network, deterministic.
